## Goal

Every push and PR runs lint, format and tests on Ubuntu and Windows with Python 3.15, so cross-platform breakage shows up at once.

## Read first

- `CLAUDE.md`
- The template's `.github/workflows/pytest.yaml` and `.github/dependabot.yml` (https://github.com/Kahncode/py-fastapi-template)

## Do

- `.github/workflows/ci.yaml`, triggered on push to `main` and on pull requests, with a matrix of `ubuntu-latest` and `windows-latest`. Steps:
  1. checkout;
  2. `astral-sh/setup-uv` with Python 3.15;
  3. `uv sync --locked`;
  4. `uv run ruff check .`;
  5. `uv run black --check .`;
  6. `uv run pytest`.
- `.github/dependabot.yml` for GitHub Actions and uv, weekly.

## Out of scope

- Docker builds and the template's build-and-push workflows: fact isn't deployed yet.

## Acceptance criteria

- [ ] The workflow runs on this task's PR, and both jobs pass.
- [ ] Breaking a test makes both jobs fail (check locally by reasoning, or with a throwaway commit you then drop).
